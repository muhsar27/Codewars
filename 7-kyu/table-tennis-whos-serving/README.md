<h2><a href=https://www.codewars.com/kata/679e3754cb041c0685865dde/train/go target="_blank">Table tennis: Who's serving?</a></h2><h3>7 kyu</h3><p>Your colleagues enjoy playing table tennis, but they often forget who should serve in each round. They ask you to create a program that will determine the serving player based on the current round number.</p><h1 id="rules">Rules</h1><ul><li>The game starts with the first round, or <code>currentRound=1</code>.</li><li>Player 1 always starts the game by serving.</li><li>A serving player alternates every two rounds</li><li><code>currentRound</code> cannot be a negative number or zero</li><li>The original game rules are simplified: there is no "deuce" exception (service does not alternate at every point after '10-10')</li></ul><h1 id="examples">Examples</h1><ul><li>The <code>Player 1</code> serves in the 1st round</li><li>The <code>Player 1</code> serves in the 2nd round</li><li>The <code>Player 2</code> serves in the 3rd round</li><li>The <code>Player 2</code> serves in the 4th round</li><li>The <code>Player 1</code> serves in the 5th round</li><li>The <code>Player 1</code> serves in the 6tx round</li><li>The <code>Player 2</code> serves in the 7th round</li><li>The <code>Player 2</code> serves in the 8th round</li><li>And so on</li></ul>
